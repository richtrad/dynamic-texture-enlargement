# Archival source

`13sccg_DT.tex` is a byte-preserved LaTeX source recovered from the author's
Google Drive archive.  Its title, abstract, section structure, equations, and
experimental discussion match the 2013 paper *Dynamic Texture Enlargement*
by Michal Haindl and Radek Richtr.  The file is an anonymized review/preprint
working source: it still contains the review identifier (`ID 0`), placeholder
author metadata, and relative references to the historical `sty/`, `img/`, and
`BIB/` directories that are not included here yet.

The institutional PDF remains the version of record.  This file is published
for provenance and reproducibility of the historical manuscript, not as a
claim that it is byte-identical to the printed proceedings version.  Its
SHA-256 is `B39928AA12718F8029A3E5185151D0FC03409A70E966A487F83C04B814886224`.
